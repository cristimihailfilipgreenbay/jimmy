# Learned Material never feeds assessments until approved

The agent can promote web Findings (Wikipedia, Tavily) into a Study Space in the background so the knowledge base grows without the Student waiting. Web content is less reliable than Notes or the Subject Library and is a possible prompt-injection carrier, so Learned Material may appear in answers (labelled "web-sourced, unreviewed") but is excluded from Quizzes, Tests and Flashcards until the Student approves it in a review list.

Considered: blocking the chat on an Approval before every save (rejected: slow, interrupts studying), and treating promoted content like Notes (rejected: a wrong answer key is the worst failure for a tutor).

Consequences: promoted text is scanned for injection before it is stored, and the review list is a required screen.
